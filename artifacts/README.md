# Curated thesis artefacts

This folder contains a small, versioned set of tables and figures used to support the thesis narrative. It is intentionally not a complete experiment-output archive.

- `figures/` contains selected publication-ready PNGs.
- `tables/` contains compact summary CSVs for the key model-comparison, baseline, audit, and Diebold–Mariano test results.

The full generated output set remains local and is excluded by `.gitignore`; rerun the pipeline described in [RUNNING_GUIDE.md](../RUNNING_GUIDE.md) to reproduce it.
